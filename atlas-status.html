How it connects

The system, end to end

Idea→ Atlas Studio→ Design Library→ Spec bundle→ Spec Kit + Ralph→ Atlas engine

Capture & design (ours) → build (reused engines) → watch, benchmark & catalog (Atlas). Nothing floats; each hand-off is a real file.

The plan

Phases

1

Capture & design layer Mostly done

The builder + Design Library. Working today. Remaining polish: grow the style set, tune question depth.

2

Agent-ready output Next

Export not just a spec but a build package — tasks.json + AGENTS.md/CLAUDE.md + review checklist, formatted to drop into Spec Kit's /speckit.specify. This is what makes the next app build fast.

3

Reuse the build engines Then

Adopt Spec Kit + Ralph inside Claude Code to generate and loop the actual code — we don't rebuild the builder.

4

Atlas engine — real servers Then

The first discovery scan that maps one of your live servers: domains, subdomains, nested apps, backups. Solves the original "missed sites" problem.

5

Enhancement engine Later

Benchmark each site vs. competitors, hunt revenue/funnel gaps, email you sourced recommendations. The "become the best" pillar.
